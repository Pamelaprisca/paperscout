# TinyBoard — finished reference

This is the finished version of the project.

Use it as a reference, not as a shortcut.

If your sandbox works differently but the behavior is correct and your code makes sense, that's fine. There are many good ways to structure a small React app.

## Run it

```bash
npm install
npm run dev
```

## What is in here

- issue board grouped by status
- search, priority and status filters
- sorting
- create and edit forms
- details page
- status updates
- delete flow
- tags, assignee and due date
- localStorage persistence
- light/dark theme
- keyboard shortcuts
- debounced search
- accessible form labels and focus states
- empty states
- toast feedback
- behavior tests

## Shortcuts

```text
N   create a new issue
/   focus search on the board
```

The shortcuts intentionally ignore input/textarea/select fields so typing doesn't trigger navigation.
